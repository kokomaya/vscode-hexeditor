# Find blocks in the table

The **Blocks** table is the main view:

- **Search** any column (Ctrl+F inside the table), **sort** by clicking a header,
  pick **Columns**, tick **Latest only** to hide superseded versions.
- **Click a row** → the Hex view jumps to the block, colors its fields and the
  Inspector decodes it. Clicking bytes in Hex highlights the owning row.
- **+** adds the block (and structurally matching ones) to a *Custom View* for side-by-side comparison.
- Right-click a row → **Ask @nvm About This Block**.
