# Ask @nvm

You don't need to know the tool to use it — just ask:

- *"Give me an overview of this dump and point out anything suspicious."*
- *"List all reset related blocks sorted by write order."* — the table is filtered for you
- *"What changed across the versions of this block?"*
- *"Arrange my workbench for investigating resets."*

Commands: `/help` · `/explain` (current selection) · `/why` (why the dump was / wasn't recognized).
Every answer ends with **Show …** buttons so you can verify each claim in the editor.
